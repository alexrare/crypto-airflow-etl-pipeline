# Crypto Data Pipeline (ETL) on Apache Airflow & Docker

Проект автоматического сбора, обработки и анализа котировок криптовалют (BTC, ETH) в реальном времени. Работает в изолированных контейнерах Docker.

## 🛠 Что используется
* **Оркестрация:** Apache Airflow 2.7.2
* **Окружение:** Docker & Docker Compose
* **Язык и библиотеки:** Python 3.8, Pandas, SQLAlchemy, yfinance
* **База данных:** SQLite

## 🚀 Как запустить проект на любом компьютере

Для запуска вам понадобятся только установленные **Docker** и **Git**.

1. **Клонируйте этот репозиторий себе на компьютер:**
   ```bash
   git clone https://github.com/alexrare/crypto-airflow-etl-pipeline.git
   ```

2. **Перейдите в папку проекта:**
   ```bash
   cd crypto-airflow-etl-pipeline
   ```

3. **Запустите всю инфраструктуру одной командой:**
   ```bash
   docker compose up -d
   ```
   *Контейнеры сами скачаются из интернета, установят Python и все библиотеки (yfinance, pandas) за 30–40 секунд.*

4. **Откройте веб-интерфейс:**
   Перейдите в браузере по адресу http://localhost:8080 (Логин: admin, Пароль: admin).

5. **Запуск пайплайна:**
   В списке на главной странице вы увидите DAG `crypto_data_pipeline_moex_yahoo`. Включите его тумблером слева и нажмите кнопку со значком «Play» (Trigger DAG) на правой стороне строки для старта сбора данных.
